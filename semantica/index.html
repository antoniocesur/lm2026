Concepto y Tipos de Bases de Datos

Bases de datos Relacionales (RDBMS)

Las bases de datos relacionales organizan la información en tablas compuestas por filas (registros) y columnas (campos). Se basan en el modelo relacional y utilizan el lenguaje SQL para realizar consultas y gestionar los datos de manera estructurada.

Ejemplos de sistemas gestores relacionales populares son MySQL, PostgreSQL y Oracle.

Bases de datos No Relacionales (NoSQL)

Las bases de datos NoSQL están diseñadas para gestionar grandes volúmenes de datos no estructurados o semiestructurados. A diferencia de las relacionales, no requieren un esquema rígido y permiten escalabilidad horizontal.

Existen distintos tipos según el modelo de almacenamiento: orientadas a documentos, clave-valor, columnas o grafos. Un ejemplo representativo es MongoDB.

Estructura de una Base de Datos Relacional

Componentes fundamentales

Para definir la estructura dentro de un modelo relacional se emplean los siguientes elementos:

  • Tablas (Entidades): Objetos principales sobre los cuales se almacena información estructurada.
  • Campos (Atributos): Columnas individuales que definen las propiedades o características de cada entidad.
  • Registros (Tuplas): Filas individuales que representan cada elemento o instancia concreta guardada en la tabla.
  • Claves primarias (Primary Keys): Campos cuyo valor es único e irrepetible para cada registro, garantizando su identificación.

Relaciones entre Tablas

Cardinalidades y Claves Foráneas

Las relaciones determinan cómo se vinculan las entidades entre sí según las reglas de negocio del sistema:

  • Relación 1:1 (Uno a uno): Un registro de una tabla se asocia únicamente con un registro de otra tabla.
  • Relación 1:N (Uno a muchos): Un registro de la primera tabla puede asociarse con varios de la segunda, pero cada registro de la segunda se vincula solo con uno de la primera.
  • Relación N:M (Muchos a muchos): Múltiples registros de una tabla pueden vincularse con múltiples registros de otra, requiriendo una tabla intermedia para romper la relación.

Para materializar estas conexiones se utiliza la Clave Foránea (Foreign Key), que es una columna en una tabla que hace referencia a la clave primaria de otra tabla.

Glosario de términos

SQL
Structured Query Language: lenguaje estándar para la gestión y consulta de bases de datos relacionales.
SGBD
Sistema de Gestión de Bases de Datos: software encargado de servir de interfaz entre la base de datos, el usuario y las aplicaciones.
Normalización
Técnica de diseño que organiza las tablas para reducir la redundancia de datos y mejorar la integridad de la información.
